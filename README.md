# Dragon Boat Festival Workspace

pnpm workspace for the Dragon Boat Festival activity apps.

## Apps

- `@dragon-boat/portal`: navigation portal, served on port `80`.
- `@dragon-boat/lucky-draw`: Dragon Boat Festival lucky draw sub app.

## Scripts

```bash
pnpm install
pnpm dev
pnpm dev:all
pnpm build
pnpm type-check
```
