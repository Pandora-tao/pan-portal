# Pan Chat 头像与思考状态设计

## 目标

在不改变现有聊天结构的前提下，让页面更明确地代表 Pan 本人，并为等待回复提供克制、清晰的动态反馈。

## 页面调整

- 将页头左上角的会话图标替换为 portal 已使用的 `pan-avatar.png`。
- 头像继续使用现有 48px 立体玻璃容器、圆角、描边和阴影，图片裁切为正方形并完整覆盖容器。
- 空状态移除图标和“开始一段即时对话”标题。
- 空状态仅展示本人视角的简短介绍：
  “你好，我是 Pan。这里是我的聊天空间，想聊什么都可以直接告诉我。”

## 思考动画

- 非流式请求等待回复时，助手消息显示“正在思考”和三个光点。
- 使用 GSAP timeline 让三个光点依次执行轻微上移、缩放和透明度变化，形成错峰呼吸效果。
- 动画只作用于光点，不缩放消息卡片，不影响正文位置和阅读稳定性。
- 消息返回、失败、停止或组件卸载时销毁 timeline，避免残留动画。
- 当系统启用 `prefers-reduced-motion: reduce` 时，不启动循环动画，光点保持静态。

## 组件边界

- `App.vue` 负责引用并展示头像资源。
- `EmptyState.vue` 保留通用文本空状态能力，但不再内置聊天图标。
- `MessageItem.vue` 根据消息状态渲染普通正文或思考指示器，并管理 GSAP 生命周期。
- 不修改聊天 API、消息数据结构或发送流程。

## 验证

- 执行 pan-chat 类型检查和生产构建。
- 在桌面和移动端浏览器检查头像裁切、空状态布局、思考动画及减少动态效果行为。
- 确认动画结束后回复正文正常替换占位状态，页面不发生明显跳动。
